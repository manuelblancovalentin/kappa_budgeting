# Handoff Checklist

<PageMeta />
---

Use this before someone leaves the project, pauses work, graduates, goes on internship, or transfers ownership.

## Current project state is documented

- [ ] `docs/current-status.md` is up to date.
- [ ] Known issues are documented.
- [ ] Next steps are documented.
- [ ] Last known good commit is listed.
- [ ] Important branches are listed.

## Reproducibility

- [ ] Setup instructions have been tested.
- [ ] Required data locations are documented.
- [ ] Required licenses/tools are documented.
- [ ] Minimal test command works.
- [ ] Main experiment command is documented.

## Knowledge transfer

- [ ] Main design decisions are documented.
- [ ] Failed approaches are documented.
- [ ] Current blockers are documented.
- [ ] Open questions are documented.
- [ ] Important contacts are listed.
